# Ahad Zamanli — Portfolio

**Canlı sayt:** https://ahadzamanli.vercel.app

Şəxsi portfolio saytım. Framework istifadə olunmayıb: bir `index.html` faylında HTML, CSS və təmiz JavaScript var.

## Xüsusiyyətlər
- 🌐 İki dil: Azərbaycan və İngilis
- 🌙 Qaranlıq rejim
- 🤖 **Echo**: spring fizikası ilə hərəkət edən, emosiyalarını mimika ilə göstərən piksel robot
- 🎬 Kinematik scroll animasiyaları, mobil üçün optimallaşdırılıb
- 🏅 Sertifikatlar üçün qalereya (telefonda sürüşdürmə ilə)

Saytın bütün məzmunu skriptin əvvəlindəki `CONTENT` obyektindədir. Layihə, sertifikat və ya link əlavə etmək üçün yalnız oranı dəyişmək kifayətdir.

## Necə qurulub
Sayt AI agent komandası ilə qurulub. Agentlərin rolları `.claude/agents/` qovluğunda, iş jurnalları isə `.team/` qovluğundadır.

## Lokal açmaq
Heç bir quraşdırma lazım deyil: `index.html` faylını brauzerdə aç.
